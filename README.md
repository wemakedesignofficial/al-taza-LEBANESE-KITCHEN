# Al Taza — Lebanese Kitchen concept

A responsive website redesign concept balancing Al Taza's Lebanese-inspired food and Kerala brand story with easy menu browsing and outlet discovery.

## Run locally

From the repository root:

```sh
python -m http.server 8000 --directory https-al-taza-com-https-al/outputs/al-taza-demo/dist
```

Open http://localhost:8000. No build step or dependencies are required. Google Fonts requires an internet connection; fallback fonts are included.

## Demo

https://wemakedesignofficial.github.io/al-taza-LEBANESE-KITCHEN/

Hosted with GitHub Pages from the `docs/` directory on `main`. Updates to this directory publish automatically.

## Features

- Animated food campaign and signature-dish feature
- Menu category filters and accessible product previews
- Kerala city shortcuts and searchable outlet finder
- Responsive layout and reduced-motion support

The editable site is in `https-al-taza-com-https-al/outputs/al-taza-demo/dist`.

This is an independent concept for discussion, not Al Taza's official website. Prices, outlet information, and branding require approval and verification before production. Ordering links currently guide visitors to outlets rather than processing orders.
